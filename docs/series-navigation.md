# Переключение сезонов на странице сериала

Для категорий «Сериал», «Мультсериал», «Аниме-сериал» прежний `SeriesPanel` показывает только один выбранный сезон вместо списка раскрывающихся сезонов. Источник данных, права редактора, оценки и условия достижения не менялись; новых миграций нет.

## Поведение

- От 2 до 6 сезонов: горизонтальная лента кнопок с номером, числом эпизодов и `aria-pressed`. Лента прокручивается внутри блока, а не растягивает страницу.
- Больше 6: нативный компактный select с номером, названием и числом эпизодов. Работает с клавиатуры и на телефоне.
- Один сезон: без лишнего переключателя и нижней пагинации. Нет сезонов: прежнее честное сообщение, без генерации эпизодов из общего числа в карточке.
- Ниже эпизодов — предыдущий/следующий сезон. Учитывается реальный порядок каталога, включая пропуски номеров; крайние кнопки недоступны. После такого перехода фокус и прокрутка переходят к заголовку выбранного сезона с отступом под шапку.
- Выбор хранится в `mg_series_season:<userId|guest>:<movieId>` через безопасный browserStorage. В памяти и storage используется ID сезона, поэтому переименование/перенумерация не ломают сохранённый выбор. Это предпочтение браузера, не серверный прогресс просмотра.
- Параметр `?season=2#series-seasons` открывает сезон по номеру и имеет приоритет над локальным выбором. Номер строго целый 1–100. Некорректный или удалённый сезон даёт сохранённый/первый доступный вариант с пояснением.
- Переключение использует native history.replaceState с `null` (Next сам сохраняет свои служебные поля) и синхронизирует useSearchParams. Не создаёт запись истории для каждого сезона и не делает дополнительный запрос API. Другие query-параметры сохраняются.
- «Ссылка на сезон» копирует абсолютную ссылку с якорем. При недоступности clipboard появляется доступное readonly-поле для ручного копирования.

## Оценки и редактор

Показатель «оценено» считает именно оценки эпизодов, а не просмотры. Отдельные оценки сезона/серий и общий прогресс достижения используют весь полученный snapshot, не только открытый сезон. Переходы не меняют оценки, просмотры или XP.

Редактор структуры и добавление сезона сохранены; редактируется только открытый сезон. При переходе или закрытии редактора с несохранёнными изменениями выбранного сезона требуется подтверждение. Во время сохранения переключатель недоступен. Удаление выбранного сезона безопасно переводит к доступному варианту. Гостю по-прежнему предлагается авторизация для оценки. Серверные проверки прав не ослаблялись.

## Проверки

- `tests/season-navigation.test.ts`: строгий разбор номера, приоритет прямой ссылки, ID/номер, перенумерация, отсутствующие/пустые/разреженные сезоны, формирование URL и разделение account/movie keys.
- `npm run test:series:browser`: реальная production-сборка и API, только localhost и marker-guarded изолированная PostgreSQL. Проверяет одну смонтированную карточку, переключение без повторного GET, память/reload/прямую ссылку/историю, реальные оценки и отсутствие XP, ошибку сохранения, clipboard fallback, клавиатуру и фокус, 8 ширин 320–1920, тёмную/светлую тему, много/один/ноль сезонов, редактор save/add/delete и защиту черновика, гостя и недоступный storage.
- Suite добавлен в последовательный браузерный этап CI. Скриншоты: `/tmp/mm-series-screenshots`.

Production, облачное хранилище и реальная БД не изменяются этими проверками. Учёт просмотра каждой серии и видеоплеер не добавлялись.
