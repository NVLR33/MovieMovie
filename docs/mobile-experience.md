# Мобильный интерфейс: навигация и быстрые действия

## Что внедрено

До 760 px включительно боковое меню заменено нижней панелью: **Главная / Каталог / Мини-игры / Профиль / Ещё**. Четыре основных назначения постоянны; в «Ещё» доступны остальные разделы, счётчики желаемого и непрочитанных сообщений, а для команды — разрешённые административные ссылки. Каталог подсвечивается также на странице материала. Второстепенные страницы выделяют «Ещё».

Переходы — настоящие ссылки с URL: работают прямые адреса, история, открытие в новой вкладке. Обычный тап использует клиентскую навигацию без перезагрузки документа. Не добавлены фоновые fetch/prefetch для всех пунктов. Для гостя «Профиль» открывает вход. На десктопе остаётся прежняя боковая навигация.

На странице материала над таббаром есть компактная панель **В список / Оценить / Отзывы**. Она доступна сразу и при прокрутке, а не только после исчезновения постера. Блок оценки в самой странице также имеет крупный мобильный триггер; маленькие половинки звёзд сохранены только на десктопе.

- Оценка открывается снизу: 20 кнопок от 0,5 до 10, каждая минимум 44 × 44 px; явное сохранение, без публикации от случайного скольжения по звёздам. Используется прежний action/optimistic update с серверной авторизацией и откатом при ошибке. Повторное быстрое сохранение ограничено существующим pending guard. Закрытие без сохранения ничего не отправляет.
- «Отзывы» открывают существующую дискуссию как мобильную нижнюю панель. Черновик сохраняется при закрытии/повторном открытии в пределах страницы. Публикация, ответы и спойлеры работают через прежние серверные проверки.
- «Ещё» и оценка — нативные modal dialog: focus trap, Escape, закрытие по фону, восстановление фокуса и блокировка прокрутки страницы. При расширении окна до десктопа мобильная панель закрывается.

## Отступы, клавиатура и доступность

Учтены `safe-area-inset-bottom/left/right`, `viewport-fit=cover` и нижний резерв под обе панели. Контент/подвал не заканчиваются под навигацией. Toast располагается над панелями. При открытии диалога, авторизации, чата или другого overlay нижние панели скрываются; они не должны перехватывать нажатия поверх модального окна.

Фокус ввода + уменьшение visual viewport более чем на 120 px скрывают нижние панели при экранной клавиатуре. Обработчики событий объединены через requestAnimationFrame, без polling/fetch. Изменение адресной строки браузера и pinch zoom не считаются клавиатурой. Поддержка конкретной клавиатуры зависит от браузера; поведение проверено эмуляцией viewport, но реальный Safari/iOS и Android стоит дополнительно проверить на устройствах.

Размер текста основных полей ввода на телефоне — 16 px, чтобы избежать автоматического zoom в iOS. Есть подписи и `aria-current`, состояния кнопок, focus-visible и reduced-motion. Увеличение страницы не запрещается. Нижняя панель не пытается сдвинуть **все** действия в нижнюю треть: это перекрыло бы контент; вниз вынесены только постоянная навигация и два контекстных действия.

## Производительность

- Админка (`AdminWorkspace`) вынесена в React.lazy/Suspense и загружается при открытии, а не входит безусловно в клиентский код каждого посетителя.
- На телефонах убраны анимации появления всей страницы и сетки карточек. Это также не даёт transform-анимациям создавать неправильный containing block для fixed-панели материала.
- Снижена интенсивность фонового blur, убран backdrop-filter на основных фиксированных мобильных поверхностях. Логотип, основные данные, оценки и возможности не упрощаются/не скрываются ради декора.
- Переход начинает страницу сверху без длинного smooth-scroll по старому контенту.

Это снижение клиентской нагрузки, а не обещание ускорения Timeweb/БД или роста конверсии. Серверные задержки, Core Web Vitals и реальную конверсию нужно измерять отдельно. Сервер, БД, DNS и хостинг этой правкой не меняются; SQL-миграция **не нужна**.

## Проверки

- `npm test`: выбор активного таба, keyboard heuristic + прежние регрессии.
- `npm run test:mobile:browser`: production Next + Chromium с изолированной marker-защищённой БД. Проверяются 320/360/390/600/760/768/1024/1280 px, минимальные touch targets, гостевой вход, «Ещё»/focus/Escape, back, клавиатура, положение fixed-действий после скролла, реальные полушаговые оценки в БД, черновик отзыва, safe area и переход на десктоп.
- `test:ui`, `test:browser`, `test:auth:browser`, `test:admin:browser`: существующие адаптивные/страничные и функциональные регрессии.

У мобильной навигации нет своих cookies, записей в БД или дублирующего хранилища рейтингов/избранного.
