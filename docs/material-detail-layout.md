# Компактные страницы фильмов и сериалов

Изменены только страницы материалов и связанные панели. Каталог, структура разделов, общие обложки, цвета рейтингов и существующие серверные функции сохраняются. Новых миграций нет.

## Композиция

- `material-detail.css` подключается последним слоем стилей. Название целиком остаётся читаемым: размер зависит от длины строки и доступной ширины контейнера, без обрезания заголовка.
- `DetailDescription` показывает три строки. Кнопка «Полное описание» появляется только при реальном переполнении после измерения текста, в том числе после изменения ширины/загрузки шрифта. Короткому описанию кнопка не добавляется. Есть обратное сворачивание и `aria-expanded`/`aria-controls`.
- Жанры и студии объединены в список без дублей: сначала четыре тега, остальные — через «Ещё N». Ссылки в каталог сохранены.
- Просмотр, трейлер и отметка «Я посмотрел» образуют первую группу. Желаемое, любимое и публикация — отдельную спокойную строку. Кнопки поиска сеансов, кинозала и мнений сообщества убраны из шапки. Подбор города/кинотеатров в настройках и разделах discovery не удалён; внешняя ссылка «Где посмотреть» сохранена.
- Комментарии находятся в отдельном заметном блоке под оценкой: понятное название, количество и кнопка «Открыть комментарии»/«Написать комментарий». Native drawer называется «Комментарии». Черновик, ответы, реакции, спойлеры и авторизация не менялись.
- Боковая информация компактнее; длинный список актёров раскрывается. На телефоне основное действие и обсуждение идут раньше служебной информации.

## Сериалы

Вместо постоянно развёрнутого блока — кнопка **«Сезоны и эпизоды» справа в верхней строке страницы**, с количеством сезонов/эпизодов, когда загружен snapshot. Она открывает центрированный native dialog с собственной прокруткой.

Внутри сохранены один выбранный сезон, переключение, ссылки на сезон, оценка сезона/каждого эпизода, внешний просмотр эпизода, ошибки/retry и редактор с прежними правами. Сведения о достижении находятся в компактном раскрывающемся блоке; прогресс всё ещё считается по полному snapshot, а не только по открытому сезону.

Прямая ссылка `?season=N#series-seasons` сразу открывает диалог с нужным сезоном. Память выбора и формат storage key не менялись. Закрытие по Escape/кнопке/фону возвращает фокус к кнопке; Tab/Shift+Tab остаются внутри. При несохранённых правках редактора требуется подтверждение, включая форму нового сезона. Гостевая авторизация закрывает диалог прежде, чем открывать форму входа. Вложенный просмотр эпизода имеет собственный цикл согласия/закрытия и возвращает к сезонам.

## Проверки

- `npm test`: 275 тестов, включая `material-detail.test.ts`.
- `npm run typecheck`, `npm run lint` (без ошибок; две прежние no-img-element warnings), `npm run build`.
- `npm run test:detail:browser`: production UI, восемь ширин 320–1920, длинное название/описание, раскрытие тегов, отсутствие удалённых действий, черновик/фокус комментариев, отсутствие постоянного блока сезонов, размеры диалога, клавиатура, прямая ссылка и гостевая авторизация.
- Регрессии: `test:series:browser`, `test:playback:browser`, `test:mobile:browser`, `test:design:browser`, `test:city-series:browser`, `test:ui`.

Production browser-тесты используют только localhost и marker-guarded изолированную PostgreSQL. Playback suite, временно проверяющий rolling-schema совместимость, следует запускать последовательно, а не одновременно с другими браузерными suite. Внешние провайдеры в playback-тестах перехватываются; доступность реальных видео этим не подтверждается.

Скриншоты — `/tmp/mm-detail-screenshots` (тестовые материалы, не production). Production/хостинг/DNS/реальная БД не изменялись.
