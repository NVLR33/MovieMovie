# Личный кинопаспорт

Профиль сочетает существующий Cinema HUD с более персональной, презентабельной
Bento-сеткой. Обложка и пользовательские украшения сохранены. Полоса уровня сразу
после обложки, до вкладок: уровень, зрительское звание, общий XP, остаток до следующего
уровня. Это индикатор, а не редактируемый slider: опыт нельзя изменить перетаскиванием.

## Виджеты

1. **Кино-карта мира** — большая плитка с настоящей ортографической SVG-проекцией.
   Глобус поворачивается кнопками, страны выбираются на карте или в доступном select.
   Нет автоспина, WebGL, canvas, внешних тайлов или запросов к map-сервису.
   Открытые страны подсвечены, выбранная страна показывает до двух просмотренных
   историй с переходами. Полный атлас открывается в режиме «Мои открытия» с выбранной
   страной; учитывается и отложенная загрузка авторизации.
2. **Твой жанр месяца** — круговая диаграмма и интерактивная легенда. Считается по
   уникальным материалам с датой отметки просмотра в текущем календарном месяце UTC,
   не по году выпуска и не по списку «Любимое». Каждый материал даёт один голос,
   разделённый поровну между его уникальными жанрами. Проценты — доля этого вклада;
   рядом отдельно указано количество материалов с жанром. Пять главных жанров и
   агрегат «Другие» отображены в круге, остальные перечислены в пояснении. Материалы
   без жанра исключаются из знаменателя и явно отмечаются. Округлённые проценты
   легенды могут давать 99/101%, сам круг использует точные значения.
3. **Текущий стрик** — последовательные дни с просмотрами по UTC. Если сегодня
   просмотров ещё нет, серия со вчера сохраняется до конца сегодняшнего дня; после
   пропущенного дня становится нулевой. Показаны рекорд по текущему дневнику и
   последние семь календарных дней. Пропуск дня не снимает XP. Удаление просмотра
   пересчитывает статистику; исторический отдельный счётчик рекордов не создавался.
4. **Следующий штамп** — реальная непросмотренная история из доступного каталога,
   открывающая хотя бы одну новую страну производства. Это объяснимая подборка по
   географии, не AI-рекомендация и не обещание персональной оценки качества.
5. **Последний штамп** — самая недавняя сохранившаяся отметка просмотра. Не выдаётся
   за любимый или недавно выпущенный фильм.

Ниже — ближайшее зрительское звание с реальным порогом просмотров, существующий
командный центр, достижения и детальная статистика. Кнопка звания открывает вкладку
«Титулы», без неработающего URL. Редактирование порядка прежних плиток сохранено.
Новые виджеты дневника не загружаются во вкладках питомца/кинокарточки/титулов.

## Правдивые данные и доступность

- Уровень растёт каждые 500 XP по текущим правилам, звания — по просмотрам. Поэтому
  интерфейс не обещает «Режиссёра через 350 XP», если такого серверного правила нет.
- Используется существующий parser стран `cinema-countries`: копродукции открывают
  несколько стран; СССР и нераспознанные названия не превращаются молча в Россию.
  Страны производства не выдаются за места съёмок. Упрощённая карта не выражает
  позицию о границах; малые территории доступны через список.
- Невалидные и будущие даты не создают просмотры месяца или стрик. Дубликаты дней,
  ID материалов и жанров не увеличивают соответствующие показатели.
- Дата обновляется на следующей полуночи UTC и при возвращении во вкладку, без
  постоянного interval. При пустой статистике — настоящие нули и полезные переходы,
  не демонстрационные числа и не пустой «100%» круг.
- Глобус загружается лениво отдельным компонентом в профиле. `d3-geo` уже был в
  проекте для генерации карты; теперь перенесён из dev в runtime dependencies.
  176 упрощённых геометрий (~150 KB JSON до сжатия) сгенерированы локально из уже
  используемого world-atlas. Генератор: `npm run map:generate`, лицензия:
  `docs/world-map-attribution.md`. Нового графического движка нет.
- На 320–760 px виджеты становятся одноколоночными. Поворот и выбор страны доступны
  без мыши. SVG описан как изображение с эквивалентным списком стран; круг имеет
  текстовую легенду. Глобус не захватывает скролл, нет бесконечной анимации; сохранены
  reduced-motion и темы/HUD/Ambient. Виджеты загрузки используют существующий busy
  контур HUD, не собственный бесконечный индикатор в простое.

## Проверки

- `tests/cinema-passport.test.ts`: пустой профиль, месяц/день UTC и смещения,
  последовательные дни, високосный год/Новый год, рекорд отдельно от текущей серии,
  будущие/невалидные даты, дубликаты, веса жанров, страны и реальные открытия.
- `npm run test:passport:browser`: production Next, настоящая регистрация и
  строго локальная БД с `mm_audit_fixture.isolated=yes`. Детерминированные часы
  браузера/фикстуры проверяют заполненный/пустой профиль, круг/легенду, стрик,
  поворот глобуса клавиатурой, выбор Японии, deep link атласа, титулы, светлую/тёмную
  тему и восемь ширин 320–1920. Скриншоты: `/tmp/mm-passport-screenshots`.
- Применяются те же audit env и optional browser deps, что в
  `docs/cinema-hud.md`. В CI тест добавлен после HUD. Созданные фильмы/просмотры
  удаляются в finally; тестовый аккаунт остаётся только в одноразовой БД.
- Общий `npm run test:ui` включает паспорт и его CSS, проверяя адаптивность профиля
  и сохранённое переключение между разделами.

Изменений production-БД, SQL-миграций и настройки инфраструктуры не требуется.
