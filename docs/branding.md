# moviemovie: название и исходный логотип

Публичное название — **moviemovie**, всегда строчными буквами в текстах, метаданных, доступных подписях и экспортах. Графическое написание на присланном логотипе сохраняется без перерисовки.

## Файлы

- `public/brand/moviemovie-logo-full.png` — неизменённый пользовательский PNG 1536×1024.
- `public/brand/moviemovie-logo.png` — кадр 1240×460 для навигации и экспорта кино-визитки: исходные буквы и ближнее свечение; обрезаны длинные вертикальные хвосты свечения.
- `src/app/favicon.ico`, `src/app/icon.png`, `src/app/apple-icon.png` — две буквы M из того же рисунка на тёмной подложке; favicon содержит размеры 16/32/48.
- `public/brand/moviemovie-social.png` — исходный рисунок на тёмной подложке 1200×630 для общего превью ссылки. Страницы фильмов сохраняют свои постеры Open Graph.

Пересоздать производные: `npm run brand:assets`. Скрипт `scripts/generate-brand-assets.mjs` использует только исходный PNG и sharp. Цвета, прозрачность и пропорции навигационного рисунка не изменяются. Иконки/превью масштабируются для своего назначения.

`src/lib/brand.ts` содержит название, базовый URL по умолчанию и путь к social image. Для реального URL используются существующие `SITE_URL` / `NEXT_PUBLIC_SITE_URL` с приоритетом серверного значения. Переменные хостинга, DNS и OAuth-регистрация этой правкой не меняются.

Верхнерегистровые editorial-подписи оборачивают название в `.brand-name`, чтобы CSS не преобразовывал его в заглавные буквы.

Технические идентификаторы `MovieGoApp`, Telegram callback/bot, существующие адреса аккаунтов в БД, ключи событий и хранилищ не переименовываются: это не публичное название и изменение нарушило бы совместимость. Публичная справка больше не рекламирует старые demo-email/общие пароли; существующие аккаунты не менялись.

## Проверка

- `npm test` — в том числе пиксельное совпадение навигационного crop с исходником и проверка иконок.
- `npm run typecheck`, `npm run lint`, `npm run build`.
- `UI_TEST_DEPS=/path/to/browser-tools AWS_EXECUTION_ENV=AWS_Lambda_nodejs22.x npm run test:brand:browser` — read-only smoke на локальном production-сервере: геометрия/загрузка логотипов при ширинах 1440/1024/760/390, регистр текста, metadata и загрузка иконок. Browser-tools должны содержать `playwright-core` и `@sparticuz/chromium`, аналогично остальным browser-аудитам репозитория.
