# Адаптивность и публичные профили

Исправления точечные: стили разделов, фон обложки и существующие функции остаются.
`responsive-repairs.css` импортируется после остальных стилей, ограничивает изменения
календарём челленджей и `.public-profile`. Убраны старые media-правила, скрывавшие
пятую карточку материала; содержимое нельзя удалять ради адаптивности.

## Содержимое вместо обрезания

- Все 12 месяцев видны: сетка 6 / 4 / 3 колонки, кнопки переносят содержимое,
  `aria-pressed` отмечает выбор, клавиатурный фокус виден. Скрытая горизонтальная
  прокрутка больше не нужна.
- В публичном профиле обложка имеет естественную высоту; имя/биография переносятся,
  действия занимают отдельную строку и не оказываются за краем обложки.
- Колонки имеют `minmax(0, 1fr)`; статистика внутри половины страницы — две колонки,
  значения могут переноситься. Панели имеют независимую естественную высоту,
  промежуток между уровнем и статистикой сохранён.
- На небольшом экране уровень занимает полную строку, мини-статистика идёт ниже;
  основные колонки складываются в одну. Постер истории не растягивается от
  глобального `history-list button > span {flex:1}`.
- Не применяются новые `overflow-x:hidden` к странице или `display:none` к данным.
  На телефоне сохраняется весь каталог, включая пятую карточку.

## Профили друзей

- API отдаёт направление заявки: `incoming` / `outgoing` / `null`. Входящую заявку
  можно принять непосредственно из профиля; исходящая подписана как отправленная.
- Изменение дружбы обновляет открытый профиль, не требует ручной перезагрузки.
  Повторное нажатие во время сохранения блокируется; ошибка не подменяет статус.
- Смена просматриваемого пользователя/аккаунта отменяет старый fetch; ответ
  отменённого запроса не обновляет UI. Для сбоя сети/500 есть «Повторить»;
  «Пользователь не найден» используется для 404, а не для любой ошибки.
- Общие фильмы считаются сервером по всей истории, а не только по шести последним
  просмотрам. Существующая метрика сходства не подменяется визуальной цифрой.
- Число активных дней больше не подписано как непрерывный стрик.

## Регрессионная проверка

`npm run test:profiles:browser` работает с production build и marker-guarded
локальной тестовой БД. Проверяет 11 ширин 320–1920 px и две темы, все 12 месяцев,
все карточки, длинные имя/биографию, большие значения статистики и границы элементов
**внутри** панелей (одного `document.scrollWidth` недостаточно).

Проверяются девять общих материалов при шести элементах недавней истории,
отправка/входящее принятие заявки, обновление статуса, отказ сохранения и повтор,
открытие чата, временная ошибка профиля и восстановление.
Скриншоты: `/tmp/mm-profile-responsive-screenshots`.
Изменений схемы БД или production-данных нет.
