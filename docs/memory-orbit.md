# Орбита воспоминаний

В личном кинодневнике прежние пять строк истории заменены пространственной лентой.
Плитка истории занимает всю ширину Bento, достижения и друзья — следующую строку.
Сохранённый порядок плиток и режим редактирования профиля работают как прежде.
Публичные профили других пользователей не изменены.

## Поведение

- «Лента» — постеры с локальной CSS perspective и translateZ/rotateX. При обычной
  прокрутке карточки мягко приближаются к плоскости экрана. Нет перехвата wheel/touch,
  горизонтального скролл-квеста или бесконечной анимации в простое.
- Личные 10/10 немного крупнее, с рамкой, свечением и подписью «Личная классика».
  0.5–4 — менее насыщенный постер с небольшими «трещинами» на рамке. Название, дата
  и оценка не затемняются. Оценки 4.5–9.5 и отсутствие оценки не считаются плохими.
  Числовая оценка остаётся видна: визуальный эффект не является единственным сигналом.
- «Список» — компактная плоская история. Выбор сохраняется в текущем браузере
  (`mg_memory_view`); недоступное хранилище не ломает переключение в текущей сессии.
- Фильтр месяца и «Личная классика» работают совместно. Пустая выборка объясняется,
  есть сброс. Даты/месяцы — UTC, сортировка от новых к старым. Невалидные даты не
  выдумываются: такие записи попадают в «Дата не указана» в конце истории.
- Первые 24 записи, затем явная кнопка следующей порции. Подгрузка не захватывает
  низ страницы и не запускается самопроизвольно. Это ограничение начального DOM,
  а не серверная пагинация: исходный API уже отдаёт историю целиком, а по нажатию
  число смонтированных карточек растёт. Виртуализация не заявляется.

## Окно воспоминания

Нажатие карточки открывает нативный dialog: материал, дата отметки, текущая личная
оценка и самый свежий собственный корневой отзыв. Чужие отзывы и ответы не берутся.
Спойлер по умолчанию скрыт и раскрывается отдельной кнопкой, можно снова скрыть.
Есть настоящая ссылка на материал (Ctrl/Cmd-click сохраняет стандартное поведение).

Диалог доступен с клавиатуры, имеет заголовок, замыкание Tab/Shift+Tab, закрытие по
Escape/кнопке/клику за пределами. Фокус возвращается к вызвавшей карточке, если она
остаётся на странице и пользователь не открыл другую панель. Контент за окном
не принимает ввод, фон окна сплошной и поддерживает светлую/тёмную тему. Длинный
отзыв прокручивается внутри окна, не расширяет экран. Мобильные docks скрываются
существующими правилами открытого dialog.

Важно: это путешествие по **сохранившимся отметкам просмотра**, а не журнал повторных
сеансов. Дубликаты movieId объединяются по последней валидной дате, отсутствующие
в каталоге материалы пропускаются. Оценка/отзыв текущие, не исторический снимок на
дату просмотра; это явно поясняется в окне. Серверная экономика XP не меняется.

## Производительность и доступность

- Без новых зависимостей, изображений эффектов, WebGL и animation-библиотеки.
- Passive scroll/resize + один requestAnimationFrame, только при событиях.
  IntersectionObserver ограничивает вычисления видимыми слотами и запасом 100 px.
  Измеряется неподвижный слот, а не трансформированная карточка, поэтому нет
  обратной связи «измерение → изменение геометрии → новое измерение».
- На телефонах глубина ограничена 48 px, на широких экранах — 145 px. При фокусе
  клавиатурой карточка становится плоской. Непрерывного will-change/GPU promotion нет.
- При reduced-motion, reduced-data, Save-Data, редактировании профиля или отсутствии
  IntersectionObserver остаётся статичная лента. Смена системного reduced-motion
  применяется сразу. Наблюдатели, RAF и слушатели удаляются при смене режима/уходе.
- Отключены входные transform-анимации обёртки профиля, чтобы координаты ленты были
  стабильными; при reduced-motion отключены и остальные анимации этой страницы.
  У большой плитки истории убран backdrop blur, не нужный на сплошном фоне.
- Семантические списки/месяцы, aria-pressed у фильтров, подписи оценок и изображения
  с пустым alt внутри уже подписанной кнопки. Кнопки управления не менее 44 px.
  Нет автоматического движения или декоративного мигания; forced-colors сохраняет
  различимый контур классики и не приглушает постеры низких оценок.

## Файлы и проверки

- `src/lib/memory-orbit.ts`: подготовка, фильтры, вычисление глубины.
- `src/components/memory-orbit.tsx` / `.css`: лента, список и диалог.
- `tests/memory-orbit.test.ts`: сортировка/UTC/дубликаты, границы оценок, чужие
  отзывы/ответы, фильтры, ограничение глубины и пустые данные.
- `npm run test:orbit:browser`: production Next + одноразовая локальная БД,
  28 фикстур; первая порция/пагинация, настоящее изменение translateZ при скролле,
  reduced motion, фильтры, спойлер, фокус/Tab/Escape, восемь ширин 320–1920,
  темы, сохранённый список, отдельный restricted-storage/Save-Data контекст,
  переход к материалу и пустая история. Скриншоты: `/tmp/mm-orbit-screenshots`.
- Общий `test:ui` включает CSS ленты. Новый production-тест включён в CI после
  кинопаспорта, использует те же UI_TEST_DEPS/AUDIT_DATABASE_URL/AWS_EXECUTION_ENV.
  Обязательны loopback URL, сокет `/tmp/mm-audit-pg` и маркер БД
  `mm_audit_fixture.isolated=yes`. Созданные фильмовые фикстуры удаляются в finally.

Миграций и изменений production-БД нет.
