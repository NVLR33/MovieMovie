# Ambient Canvas

На странице фильма/сериала оформление сайта получает палитру постера: общий фон,
поверхности, акценты, боковое и мобильное меню, границы, кнопки и градиентное свечение.
Цвета и поверхности переходят за **700 ms**. При уходе со страницы возвращается
выбранная пользователем тема. Семантические цвета рейтингов и статусов не меняются.

Переключатель **«Атмосфера фильма»** находится в единой панели **«Настройки»** в шапке сайта. Над постером отдельной кнопки больше нет; см. `docs/site-settings.md`.
Выбор сохраняется только в текущем браузере (`mg_ambient_canvas`) и синхронизируется
между вкладками; недоступность localStorage не ломает переключатель.

## Реализация

- `src/lib/ambient-palette.ts`: гистограмма RGB, взвешенная по распространённости
  и насыщенности. Отбрасываются прозрачные пиксели, почти чёрные/белые поля,
  малонасыщенные надписи и единичный шум. Выбираются до трёх различимых цветов.
  Для монохромного постера используются оттенки исходного цвета, не выдуманный
  контрастный цвет.
- `src/lib/ambient-image.ts`: клиентский canvas **40 × 56**, анонимная загрузка,
  `no-referrer`, тайм-аут 3,5 секунды. Сначала постер, при неудаче — backdrop.
  Нет новой runtime-зависимости, серверного прокси или SQL-миграции.
- Кеш до 64 URL: успешный результат 30 минут, неудачный — минуту, не более четырёх
  одновременных анализов. Изображения свыше 20 Мп не читаются в canvas после загрузки;
  это не предотвращает их первоначальную загрузку/декодирование браузером.
- `src/components/ambient-canvas.tsx`: применение `--ambient-*` к корню документа,
  отмена применения устаревшего результата при навигации, восстановление темы при
  размонтировании, пересчёт токенов при смене светлой/тёмной темы без повторного чтения
  картинки. Предыдущая палитра сохраняется до готовности следующей.
- `src/components/ambient-canvas.css`: типизированные цветовые CSS properties для
  интерполяции градиентов и 700 ms transitions для основных поверхностей. Нет
  бесконечной анимации цвета; при `prefers-reduced-motion` переходы отключены.

## Доступность и ограничения

Тёмные/светлые сплошные поверхности и акцентные цвета рассчитываются отдельно:
контраст текста/вторичного текста и текста на основных кнопках проверяется unit-тестами
на WCAG AA 4,5:1. Это проверка токенов, а не заявление о полном WCAG-аудите всех
полупрозрачных слоёв приложения. В светлой теме вводится тёмная подложка под
семантический рейтинг, исправляется цвет описания и метаданных.

На телефонах уменьшены blur и непрозрачность фонового изображения, переключатель
имеет высоту не менее 44 px. При Save-Data или `prefers-reduced-data` дополнительный
анализ пропускается. При `prefers-reduced-transparency` фоновый декоративный слой скрыт.

Внешний хост картинки должен разрешать CORS-чтение. Если не разрешает, canvas запрещён,
изображение недоступно или превышен тайм-аут, остаётся обычная тема и исходный размытый
фон. Если доступен backdrop, палитра берётся из него. Обхода CORS нет. При выключении
атмосферы декоративный слой также убирается. Обрабатываются только HTTP(S) URL без
credentials и безопасные root-relative пути; data/blob/javascript URL не анализируются.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:ambient:browser
npm run test:ui
```

`test:ambient:browser` запускается против production Next и **только изолированной**
БД с маркером `mm_audit_fixture.isolated=yes` и Unix-сокетом `/tmp/mm-audit-pg`.
Использует те же `AUDIT_DATABASE_URL`, `UI_TEST_DEPS`, `AUDIT_BASE_URL` и
`AWS_EXECUTION_ENV`, что и остальные browser-аудиты (см. `.github/workflows/quality.yml`).
Изменённые строки фильмов восстанавливаются, созданные фикстуры удаляются в `finally`.
В CI тест включён после мобильного browser-аудита.

Браузер генерирует детерминированные PNG (оранжево-синий и розовый), а приложение
анализирует их настоящим canvas. Проверяются смена палитры, кеш, cleanup, сохранение
выключения, светлая/тёмная тема, 320/390/760/1280 px, reduced motion, 700 ms,
CORS-отказ, запрет canvas/localStorage, Save-Data и гонка загрузки при навигации.
Из аргументов тестового Chromium специально исключён `--disable-web-security`, чтобы
проверка CORS действительно работала. Скриншоты сохраняются только в
`/tmp/mm-ambient-screenshots`, не в репозитории.
