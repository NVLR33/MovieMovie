# Библиотека рейтингов

## Страница и навигация

`/top` теперь открывает библиотеку списков: квадратная мини-обложка, название,
фактическое число материалов, личный счётчик просмотров и кольцо прогресса.
Обложки сделаны CSS + Lucide SVG, без изображений со сторонних сайтов и новых
зависимостей. Оформление следует палитре сайта и светлой/тёмной теме: тёплые
обложки оценок, синие популярности, розовые любимого. Фоновое свечение статичное,
ненавязчивое; настройки Ambient Canvas на страницах фильмов не затронуты.

На главной полная библиотека рейтингов больше не монтируется. Вместо неё добавлен
компактный постерный топ-5 (см. ниже). Пункт «Лучшие материалы» в
боковой/мобильной навигации и переход из каталога сохранены. Не путать его с
пользовательским лидербордом «Рейтинг»: тот не менялся.

Библиотека содержит девять списков: топ-10/50/100 по трём существующим критериям.
Категории: все материалы и шесть существующих типов. Выбранная категория хранится
в URL (`/top?category=Фильм`). Не добавлялись внешние Top 250/500, ожидаемые релизы
или искусственные позиции, которых нет в нашей базе/системе.

Нажатие строки открывает существующую детальную выдачу с местами, оценками,
посещениями и отметками просмотра. Все старые URL вида
`/top?metric=favorites&limit=50&category=Фильм` продолжают открывать конкретный топ.
Наличие `metric` или `limit` выбирает детальную выдачу, отсутствие обоих — библиотеку.
«Все списки рейтингов» возвращает к библиотеке той же категории. Настоящие ссылки
сохраняют открытие новой вкладкой, есть работающие Back/Forward и обновление страницы.

## Данные и честность прогресса

Ранжирование по-прежнему использует `rankMaterials`:

- Оценки — средняя оценка пользователей с настоящими голосами; прежние tie-breaks.
- Популярность — посещения страниц материалов, **не** пользовательские отметки
  просмотра. Это явно пояснено в описании. Метод и серверная аналитика не менялись.
- Любимое — число пользователей, у которых материал сейчас в любимом, не лайки.

`buildRankingLists` сортирует каталог только три раза (по разу на критерий), затем
берёт вложенные размеры 10/50/100. Прогресс — пересечение уникальных ID конкретного
ограниченного списка с текущими `data.watches`. Один просмотр не считается дважды.
Знаменатель — фактическое количество в выдаче, а не целевой размер. Если в топ-100
пока 12 материалов, показывается «3 из 12» и пояснение, что список растёт. Пустой
список — «0 из 0 / Пока нет материалов», а не 100% завершённый топ. Полный непустой
список — «Весь список просмотрен». Процент округляется, кольцо использует точную долю.

Гостю доступны все списки, вместо нулевого личного прогресса написано «Доступен после
входа». После входа/изменения просмотров/получения новых данных прогресс пересчитывается.
Рейтинги динамические: изменение состава может менять и личный прогресс; это
объяснено внизу. Никаких постоянных наград за завершение списка и дополнительных XP
не начисляется. Новых API, миграций и изменений production-БД нет.

## Доступность и адаптивность

Секции критериев с заголовками и семантическими списками. Вся строка — ссылка с
focus-visible; прогресс имеет подпись «Просмотрено X из Y», декоративное кольцо и
обложка скрыты от скринридеров. Категории — кнопки с aria-pressed и высотой от 44px.
На телефонах прогресс переносится под название, без горизонтальной прокрутки.
При reduced-motion выключены переходы строки, а forced-colors сохраняет обводки.

## Проверки

- `npm test`: базовые ранжирование/фильтры/границы плюс тесты девяти списков,
  пересечений просмотров, настоящих знаменателей, пустой категории и гостя.
- `npm run test:ui`: настоящая React-оболочка, отсутствие блока на главной,
  библиотека на восьми ширинах 320–1920 и прежние проверки детального любимого.
- `npm run test:rankings:browser`: production Next и одноразовая локальная БД с
  обязательным marker `mm_audit_fixture.isolated=yes`, loopback base URL и сокетом
  `/tmp/mm-audit-pg`. Реальные записи фильмов/оценок/просмотров/любимого создаются в
  изолированной БД, удаляются в finally; производственные подключения запрещены.
  Проверяет библиотеку/деноминаторы, пересечение с детальным списком, категории,
  переход/назад/историю, сохранение URL, пустую выборку, гостя, клавиатуру, обновлённую
  отметку просмотра, восемь ширин и обе темы. Скриншоты — `/tmp/mm-ranking-screenshots`.
- В CI новый production browser-тест выполняется после `test:orbit:browser` с теми
  же `UI_TEST_DEPS`, `AUDIT_DATABASE_URL` и `AWS_EXECUTION_ENV`.


## Компактный топ-5 на главной

`src/components/home-top-five.tsx`: отдельная горизонтальная постерная витрина,
не возврат прежней большой карточки рейтингов. Крупные декоративные номера стоят
за постерами, ниже — название, год и категория; сверху постера — метрика выбранного
критерия. Возрастное ограничение остаётся на постере, если оно заполнено в каталоге.
При ошибке загрузки изображения появляется нейтральная иконка, а название и ссылка
остаются доступны. Витрина использует тот же `rankMaterials`, берёт первые пять из
топ-10 по всем категориям, не заполняет пустые позиции вымышленными материалами.

Критерии «По рейтингу / По просмотрам / По любимому» переключаются локально, не
меняют URL главной. «Весь топ-10» ведёт к соответствующему детальному рейтингу.
В названии/пояснении просмотры отделены от личных отметок: это посещения страницы.
Любимое — счётчик пользователей, а не лайки. Подписанная ссылка на постер открывает
материал; Ctrl/Cmd-click работает стандартно. Номера и картинки декоративные,
название ссылки озвучивает место, название, год, категорию, выбранную метрику и
возрастное ограничение, если оно есть.

На широких экранах пять элементов в строку; до 1100px — локальная горизонтальная
лента со scroll-snap proximity, свайпом, клавиатурной прокруткой и кнопками по 44px.
Страница не расширяется горизонтально. При смене критерия позиция ленты сбрасывается
в начало. Автопрокрутки/таймеров нет, reduced-motion отключает hover-сдвиг и плавный
скролл стрелками. Цвета адаптированы к обеим темам и forced-colors.

`test:rankings:browser` дополнительно проверяет пять мест, переключение всех трёх
критериев, только реальные favorite-сигналы, порядок по посещениям, стрелку на
телефоне/сброс позиции, переход в выбранный топ-10, обе темы и пустую гостевую
выборку. Скриншоты `/tmp/mm-ranking-screenshots/home-five-{dark,light,mobile}.png`.
`test:ui` проверяет узкую реальную выборку (три материала / два в любимом) и отсутствие
горизонтального overflow главной на восьми ширинах.
