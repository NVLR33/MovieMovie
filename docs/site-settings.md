# Единый центр настроек

Все общие настройки открываются одной кнопкой «Настройки» в шапке, в том числе на странице материала. Старые отдельные переключатели языка, темы, сезона и кнопка атмосферы над постером удалены. Уведомления и меню аккаунта остаются отдельными действиями. Украшения профиля доступны по ссылке внутри панели.

## Интерфейс

- Пять наглядных образцов темы: тёмная, светлая, розовая, фиолетовая, жёлтая.
- Явный выбор русского/английского. Пояснение честно ограничивает перевод навигацией и поддерживаемыми элементами; описания, названия и отзывы не переводятся. Обновляется `html.lang`.
- Сезон: автоматически по текущему месяцу, выключено либо один из четырёх сезонов. Панель объясняет текущий автоматический выбор.
- Сезонные частицы и свечение — независимые переключатели. При выключенном сезоне они недоступны, но предыдущие значения сохраняются.
- «Атмосфера фильма» управляет существующим извлечением цвета постера/Canvas. Это не сезонное свечение. Экономия трафика и ограничения Canvas по-прежнему учитываются.
- Все изменения применяются немедленно. «Готово» только закрывает панель.
- Сброс спрятан в раскрываемое подтверждение, перечисляет затрагиваемые параметры: тёмная тема, русский, автоматический сезон, включённые сезонные эффекты/атмосфера фильма. Оценки, история и украшения профиля не меняются.

## Сохранение и доступность

Тема/язык используют существующие `mg_theme`/`mg_lang` и profile action для авторизованных пользователей. Браузерный выбор имеет прежний приоритет. Ошибка записи в профиль показывается отдельно с повтором синхронизации; локальное оформление остаётся выбранным. Пока запись выполняется, другие варианты темы/языка и сброс заблокированы, текущий выбранный radio остаётся доступным для фокуса.

Сезон, частицы, свечение и атмосфера фильма сохраняются только в этом браузере через существующие storage keys. Блокировка localStorage не ломает панель: действует сессионный fallback. Системный `prefers-reduced-motion` отслеживается и объясняется; частицы скрывает прежний CSS, цветовые эффекты сохраняют прежнюю ограниченную анимацию.

Используется native modal dialog с подписями, fieldset/radio, checkbox `role=switch` и пояснениями через `aria-describedby`. Фокус остаётся внутри, Escape/фон/крестик/«Готово» закрывают панель, фокус возвращается на кнопку. На открытии закрываются старые popover аккаунта/уведомлений/поиска. При навигации панель демонтируется. На узких экранах — нижний лист с прокруткой и закреплённым футером. Учтены safe-area, forced-colors и отсутствие hover на телефоне.

## Проверки

`npm run test:settings:browser` запускает production browser suite только против localhost и marker-guarded изолированной PostgreSQL fixture. Покрытие: одна точка входа, 5 тем/2 языка, сезоны/частицы/свечение/Canvas, reload, профильная запись/ошибка/повтор, reduced motion, сброс, клавиатура/focus/Escape, 8 ширин 320–1920, light/dark, заблокированный storage. Скриншоты: `/tmp/mm-settings-screenshots`.

Общие действия с новой панелью вынесены в `tests/integration/settings-controls.mjs`; существующие ambient/HUD/passport/orbit/pulse/showcase/rankings browser suites используют реальные radio/switch вместо удалённого hover-меню. CI запускает новый suite последовательно с остальными Chromium-проверками. Production/миграции/схема БД не затрагиваются.

При регрессии также исправлена гонка прокрутки домашнего топ-5: после смены критерия лента сбрасывается после DOM-перестановки, а не до неё. Проверка ожидает фактического нулевого scrollLeft, включая незавершённый свайп.
